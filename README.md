# Bilkoll
Integritetspolicy för BilKoll
Senast uppdaterad: 29 oktober 2026

Din integritet är viktig för oss. Denna integritetspolicy förklarar hur appen BilKoll hanterar dina uppgifter och behörigheter på din enhet.

1. Insamling och användning av information
BilKoll samlar inte in, lagrar inte och delar inte några personuppgifter eller enhetsuppgifter till externa servrar eller tredje part. All databehandling sker lokalt på din enhet.

2. Behörigheter som appen använder
Kamera (android.permission.CAMERA): Används endast lokalt på enheten för teckenläsning (OCR) av registreringsskyltar. Bilder eller kameraströmmar sparas inte och skickas aldrig utanför din enhet.
SMS (SEND_SMS, RECEIVE_SMS, READ_SMS): Används exklusivt för att skicka registreringsnummer till Transportstyrelsens offentliga SMS-tjänst (71640) och ta emot fordons- och ägaruppgifter. Ingen SMS-data lagras externt eller skickas till någon tredje part.
Internet (INTERNET): Används endast för valfri kompletterande sökning eller visning av information.
Vibrator (VIBRATE): Används för haptisk feedback i gränssnittet när en nummerplåt identifierats.
3. Tredjepartstjänster
Appen använder Google ML Kit för lokal textigenkänning (OCR) på enheten. ML Kit behandlar bildrutor lokalt på din mobiltelefon och överför inga bilddata till Google.

4. Lagring av historik
Sökningar och historik sparas endast lokalt i appens interna minne på din mobiltelefon. Du kan när som helst rensa din sökhistorik direkt i appen.
